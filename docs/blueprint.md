# **App Name**: AutoMobility Hub

## Core Features:

- Vehicle Mega Menu: Implement a mega menu for easy navigation across all vehicle types: EVs, Hybrids, Trucks, SUVs, Sedans, and Ebikes.
- Categorized Listings: Arrange vehicles in well-defined categories for intuitive browsing.
- Detailed Specs: Car specs should be displayed for each individual car listing, along with detailed features.
- AI-Powered Recommendation Engine: The recommendation engine helps users discover and find new vehicle and E-Bikes using our search tool

## Style Guidelines:

- Primary color: Deep blue (#1A237E) to convey trust and reliability in the automotive industry.
- Background color: Light gray (#F5F5F5), providing a neutral backdrop that highlights the vehicle images.
- Accent color: Electric blue (#7DF9FF), used for interactive elements and calls to action.
- Headline font: 'Space Grotesk' sans-serif for a modern, tech-forward feel, well-suited to EVs and Ebikes. Body font: 'Inter' sans-serif for clear readability in vehicle specs and descriptions.
- Use sharp, modern icons to represent vehicle features and categories. Follow the stylistic conventions used in automotive interfaces.
- Employ a grid-based layout to present vehicle listings in a structured, visually appealing manner.
- Use subtle transitions and animations for a smooth browsing experience.
