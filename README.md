# Comfort Homes - Real Estate Platform

A professional modern, AI-powered real estate platform for Comfort Homes, specializing in verified land and property listings in Kenya.

## Features

- **AI Land Advisor**: Interactive property-specific and site-wide AI assistants powered by Genkit.
- **Project Management**: Secure Admin Dashboard to manage land projects, blog posts, and site gallery.
- **Dynamic Search**: AI-powered search recommendations based on user intent.
- **Financing Tools**: Integrated loan calculator for installment plans.
- **Mobile Responsive**: Built with Next.js and Tailwind CSS for a seamless experience on all devices.

## Tech Stack

- **Frontend**: Next.js 15 (App Router), React, ShadCN UI, Tailwind CSS.
- **Backend**: Firebase (Firestore, Auth, Storage).
- **AI**: Genkit with Google Gemini.

## Getting Started

1. **Clone the repository**:
   ```bash
   git clone [your-repo-url]
   cd comfort-homes
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up Environment Variables**:
   Create a `.env` file with your `GEMINI_API_KEY`.

4. **Run Development Server**:
   ```bash
   npm run dev
   ```
